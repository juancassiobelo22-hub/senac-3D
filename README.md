# Simulação 3D — Centro de Distribuição Senac Imperatriz

- `index.html` — simulação 3D interativa em arquivo único (funciona offline, no PC e no celular).
- `Simulacao-3D-Centro-de-Distribuicao.pptx` — apresentação; o botão do slide 3 abre a simulação.
- `src/` + `build.mjs` — código-fonte. Para regerar o `index.html`: `npm install && npm run build`.
